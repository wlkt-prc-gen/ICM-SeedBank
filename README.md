# ICM Seed Bank

One-use Markdown instructions for establishing clear, reviewable AI workspaces. Pick a seed, open its README, and give that file to your agent in the workspace you authorize.

| Seed | Use it to |
|---|---|
| [ICM Structure](01_ICM_Structure/README.md) | Build a localized workspace with one Questions file, a concise AGENTS.md, and meaningful work areas |
| [Wiki](Wiki/README.md) | Establish concept cards, source summaries, indexing, and source processing |
| [README as Design](README_as_Design/README.md) | Put human navigation and agent instructions in one folder entry point |

## How to start

1. Choose the seed that fits the outcome. Each file is self-contained.
2. Give its GitHub file link or full contents to your agent. Confirm the destination and the permissions.
3. Review the intake or proposed changes. The agent waits for approval before building.
4. After setup, use the generated workspace instructions. Do not install the seed as a recurring skill.

For a new workspace, start with ICM Structure. It applies README as Design by default and keeps setup origins in Help. Wiki and README as Design also work independently in an existing workspace. Reapplying a seed should repair agreed gaps rather than overwrite existing work.

## Boundaries

These are AI-assisted setup instructions, not a software runtime or a guarantee of agent behavior. Generated work requires review. Keep client data, source documents, credentials, and completed questionnaires in authorized private workspaces, outside this repository.

README files serve humans first, then carry compact agent contracts. Tool-required AGENTS.md or CLAUDE.md entry points remain in place. Existing workspace rules take precedence.

## Versions and changes

Current package version: 2.0.2. ICM Structure is version 2.0.2; Wiki and README as Design remain version 1.0.0. See [changes](CHANGELOG.md). For repeatable setup, use a GitHub link pinned to a reviewed commit rather than assuming main will stay unchanged. Review later changes before applying them to an existing workspace.

## Reuse

You may use and adapt these instructions to create and operate your own workspaces. Preserve source attribution when redistributing the seed text. This permission applies to these seed instructions, not to third-party sources or private materials used in a generated workspace.
